# Convert a master Giotto object to suite

Convert a master Giotto object to suite

## Usage

``` r
giottoMasterToSuite(gobject, expression_feat = "rna")
```

## Arguments

- gobject:

  A Giotto object created with master version

- expression_feat:

  available features (e.g. rna, protein, ...)

## Value

A Giotto object compatible with suite version
