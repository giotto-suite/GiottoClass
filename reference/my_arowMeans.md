# my_arowMeans

my_arowMeans

## Usage

``` r
my_arowMeans(x)
```

## Arguments

- x:

  data to use

## Value

numeric

## Examples

``` r
m <- matrix(rnorm(100), nrow = 10)

my_arowMeans(m)

#>  [7] -0.01357922  0.18863110  0.26899955 -0.19844309
```
