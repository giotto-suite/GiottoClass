# .create_delaunaynetwork_geometry_3d

Create a spatial 3D Delaunay network with geometry

## Usage

``` r
.create_delaunaynetwork_geometry_3d(
  spatial_locations,
  sdimx = "sdimx",
  sdimy = "sdimy",
  sdimz = "sdimz",
  options = options,
  ...
)
```

## Value

spatial 3D Delaunay network with geometry
