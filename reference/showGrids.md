# Show Spatial Grids

Show Spatial Grids

## Usage

``` r
showGrids(...)
```

## Arguments

- ...:

  Arguments passed on to
  [`showGiottoSpatGrids`](https://giotto-suite.github.io/GiottoClass/reference/showGiottoSpatGrids.md)

  `gobject`

  :   giotto object

  `nrows`

  :   number of rows to print

## Value

prints name of available spatial grids
