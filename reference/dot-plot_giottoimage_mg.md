# .plot_giottoimage_mg

get and plot a giottoImage either directly or from a giotto object

## Usage

``` r
.plot_giottoimage_mg(gobject = NULL, image_name = NULL, giottoImage = NULL)
```

## Arguments

- gobject:

  giotto object

- image_name:

  name of giotto image
  [`showGiottoImageNames`](https://giotto-suite.github.io/GiottoClass/reference/showGiottoImageNames.md)

- giottoImage:

  giottoImage object

## Value

plot
