# S4 giotto points Class

Giotto class to store and operate on points data

## Value

giottoPoints

## Details

Contains vector-type feature data

## Slots

- `feat_type`:

  name of feature type

- `spatVector`:

  terra spatVector to store point shapes

- `networks`:

  feature networks

- `unique_ID_cache`:

  cached unique feature IDs that should match the spatVector slot

## Examples

``` r
giottoPoints()
```
