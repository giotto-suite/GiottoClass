# Edge statistics parameters

Parameter class for
[`analyzeData()`](https://giotto-suite.github.io/GiottoClass/dev/reference/analyzeData.md)
that computes, per feature, the sums over a spatial network from which
edge statistics such as Moran's I, Geary's C and join counts are
derived. Build it with
[`edgeStatsParam()`](https://giotto-suite.github.io/GiottoClass/dev/reference/edgeStatsParam.md).
