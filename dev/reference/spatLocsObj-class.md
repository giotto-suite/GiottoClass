# S4 spatLocsObj Class

Framework to store spatial location information

## Value

spatLocsObj

## Slots

- `name`:

  name of spatLocsObj

- `coordinates`:

  data.table of spatial coordinates/locations

- `spat_unit`:

  spatial unit tag

- `provenance`:

  origin of aggregated information (if applicable)

## Examples

``` r
GiottoData::loadSubObjectMini("spatLocsObj")
```
