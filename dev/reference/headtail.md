# Head and tail

Get the head (first values) or tail (last values) of an object

## Usage

``` r
# S3 method for class 'giottoBinPoints'
head(x, n = 6L, ...)

# S3 method for class 'giottoBinPoints'
tail(x, n = 6L, ...)
```

## Arguments

- x:

  object

- n:

  `integerlike` how many to get

- ...:

  additional arguments to pass to other methods

## Value

the same class as `x`
