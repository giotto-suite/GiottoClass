# Update giotto polygon object

Update giotto polygon object

## Usage

``` r
updateGiottoPolygonObject(gpoly)
```

## Arguments

- gpoly:

  giotto polygon object

## Value

GiottoPolygonObject

## Examples

``` r
g <- GiottoData::loadSubObjectMini("giottoPolygon")

updateGiottoPolygonObject(g)
```
